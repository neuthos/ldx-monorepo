## 1. Summary

### TL;DR

Test plan for the governed two-step slip cancellation (Confirmed → 取消待ち → 取消確定) extended to Arrival, Shipment, Store Sales, and Store Sales Return by replicating the approved phase 1/2 architecture. Highest risks: (1) cross-domain cascade correctness with full-chain reuse (Store Sales → Sales → Purchase; Arrival ↔ Shipment movement pair), (2) inventory / lot / outstanding reversal side effects, (3) the newly USER-APPROVED Store Sales blocker set (point/coupon/tax-free, external origin, POS closing) and the phase-1 `_cancel_store_sales` alignment, (4) regression of the approved phase 1/2 suites. All product decisions are resolved (no PENDING rows). Batch-registration upload cancellation is **out of scope** — FR-03/09/15/19 Rejected by human 2026/08/19 ("Batch Register stays separate as before").

## 2. Data Preparation Summary

- **Core slips**: `stock.picking` `transfer_type='arrival'`/`'shipment'` and `store.sales` `sales_operation_type='sales'`(STS-)/`'return'`(RSTS-) in `draft` and `done`; variants: clean Confirmed, 取消待ち, 取消確定, closing-locked (締め via `change.lock.date.history`), POS-closed (`pos_closing` snapshot / `daily_sale_id`).
- **Arrival fixtures**: linked Purchase `account.move` Draft / Confirmed+unpaid / Confirmed+Paid; `order.master` with outstanding; inter-store movement pair (`inter.store.movement`) both Confirmed; own unconsumed lot L1 + shared lot L2.
- **Shipment fixtures**: Sales `sale.order` Draft; Confirmed+billing draft; Confirmed+billing Confirmed; linked arrival Waiting and Confirmed; `receipt.order` Confirmed with shipment created.
- **Store Sales fixtures**: RSTS Draft/Confirmed via `return_store_slip_id`; `ec.order.receive` Confirmed; Sales without/with confirmed `warehouse.return.instruction`; blocker variants — point payment, point grant, coupon consumed, tax-free, formal receipt issued (領収書), credit-card payment, Smaregi/POSCM/TeamStore origin (`external_link`, `ext_poscm`, `ext_teamstore`).
- **Return fixtures**: `ec.order.return` Confirmed; confirmed Sales Return; original Confirmed STS.
- **Actors**: Read / Write / Approve / Write+Approve for each of the four new authority items; a guest with none.
- **Selection sets**: empty, single, many; mixed Confirmed+取消待ち+Draft; mixed STS+RSTS; >50 rows (chunk boundary); includes 取消確定 (error).
- **Locale/timezone**: JP and EN sessions; a slip cancelled near midnight UTC rendering 取消日時 in JST.
- **Cleanup**: synthetic data only; markers and created slips removed per suite teardown.
