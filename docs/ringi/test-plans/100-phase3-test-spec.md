**Consumers:** FE, BE, and E2E teams working in parallel. Technical register throughout.

## 1. Summary

### TL;DR
78 test cases cover all 29 Approved FRs of the four cancellation domains (Arrival, Shipment, Store Sales, Store Sales Return), the shared UX contract, the authority model, and an extended E2E/API suite (TC-38..78). Out of scope by human decision: the four batch-registration-upload FRs (FR-03/09/15/19 — rejected: separate cancellation batch-registration screens as phase 1/2). One BOUNDARIES letter is Partially covered (R — explicit double-confirm TC still to add).

### Coverage and confidence
- FR coverage: 29/29 Approved FRs. Rejected FRs excluded and noted. No Question FRs remain.
- Confidence: 85 percent (estimated) — 1:1 sheet traceability; BOUNDARIES walked with one partial; blast radius traced; graph evidence from feat/ringi-100-cancellation BE and phase-2 FE.

### Healthy pyramid
- Target: Unit ~70 / Integration 15-20 / E2E 5-10 (percent, by rows).
- Actual (by rows): Unit 15/78 (19), Integration 10/78 (12), E2E 53/78 (67) percent.
- Assessment: risk-adjusted deviation — the four PRD scenario suites are journey-shaped and the appended team suite (TC-38..78) is E2E/API-heavy by design; each E2E row consolidates several PRD sub-scenarios. Sheet rows and this table are 1:1 (same TC-IDs and counts).

### BOUNDARIES summary
- B Covered (TC-04, 05, 16) — O Covered (TC-03, 33) — U Covered (TC-04, 35) — N Covered (TC-01, 04) — D Covered (TC-33) — A Covered (TC-22, 37) — R Partially covered (TC-24; explicit double-confirm TC pending) — I Covered (TC-25, 10) — E Covered (TC-28, 31, 35) — S Covered (TC-02, 03, 05).

### Assumptions
- Closing-date field for pickings pinned at implementation (candidates scheduled_date / date_done); store.sales uses sales_date (verified).
- E2E page objects follow the phase-1/2 CancellationBatchRegistration pattern.

## 2. Data Preparation Summary
- Slips per domain (stock.picking arrival/shipment; store.sales STS/RSTS): Confirmed clean, Waiting/Draft, Pending Cancellation, Cancellation Confirmed, wrong-type variants, closing-locked.
- Link fixtures: Paid/unpaid/draft Purchase; billing-confirmed/draft Sales; movement pairs; Customer Order with shipment; RSTS draft/confirmed; EC order/return; Sales with/without Sales Return.
- Blocker fixtures (Store Sales): point payment, granted points, coupon, tax-free, Smaregi/POSCM/TeamStore origin, POS/daily-closed; a receipt-issued cash slip (must still cancel).
- Actors: Read / Write / Approve / Write+Approve per cancellation item; guest.
- Baselines: stock free/reserved/total, lots, order.master outstanding, movement history.
